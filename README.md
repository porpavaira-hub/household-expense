# Household Expense & Bill Reminder System

Java 17+ , Swing UI, SQLite database.

## Run (Maven)
    mvn -q compile exec:java -Dexec.mainClass=com.household.Main

## Run (VS Code)
Open the folder, install "Extension Pack for Java", open Main.java and press Run.

The database file `household.db` is created automatically in the project folder on first run.
